# Initiative + Bleed Tracker

Modified community version of the Owlbear Rodeo Initiative Tracker. At the beginning of a character's turn (when Next is pressed), it consumes one charge from each active Bleed stack, totals their damage, and shows only a red number (for example, −4) beside the character's name. The number remains for that turn and is cleared when the next turn begins. It does not change token HP.

This is not an official Owlbear Rodeo extension. It is derived from https://github.com/owlbear-rodeo/initiative-tracker and distributed under GPL-3.0; see LICENSE.

Install manifest: https://herbybow.github.io/Effect-Tracker/initiative/manifest.json

Remove the official Initiative Tracker from the room before using this modified version to avoid duplicate controls.
